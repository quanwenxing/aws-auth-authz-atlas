# AWS認証・認可ガイドサイト

## 概要
AWS上の認証認可まわり（IAM / IAM Identity Center / Cognito / OAuth 2.0 / OpenID Connect / SAML / Federation / STS）を、初心者向けに整理した静的HTML資料サイト。

## 成果物
- `index.html` — GitHub Pages にそのまま配置できる単一ページサイト
- `RESULT.md` — 完了内容と公開先メモ
- `LOG.md` — 作業ログ
- `META.json` — メタ情報

## 公開想定
- GitHub repository: `aws-auth-authz-atlas`（予定）
- GitHub Pages: `https://quanwenxing.github.io/aws-auth-authz-atlas/`

## 内容
- 認証と認可の違い
- OAuth 2.0 / OIDC の基礎
- IAM / STS / Identity Center / Cognito の役割分担
- SAML / OIDC federation の関係
- 実務パターン別のおすすめ構成
- 主要キーワード一覧
- 一次情報リンク付き出典
